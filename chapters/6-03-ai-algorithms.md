# 6-03 AI 中的算法：计算机如何学会"想"

> 前两章的算法，都是「人把步骤写清楚，交给机器一步步执行」。但有一类问题，人根本写不出步骤——「怎么一眼认出这是猫？」我们答不上来「规则」，却一眼就能认。机器能不能也「不用写规则，自己学会」？能。这就是人工智能（AI）的核心转身：**从「人写规则」到「机器从数据里自己找规则」。** 这一章讲清三件事：智能是怎么来的、机器是怎么「学」的、以及它到底会不会「想」。

---

## 3.1 传统算法 vs 机器学习：从「写规则」到「找规则」

先看一个经典难题：**让计算机认出一张图里有没有猫。**

- **传统思路**：程序员写规则——「有尖耳朵」「有胡须」「有竖瞳孔」……写了几百条，结果一张猫耳朵被遮住的照片就认不出来。**世界太复杂，规则永远写不全。**
- **机器学习思路**：不写规则，直接喂给机器**一万张标好答案的图**（这张是猫、那张不是猫），让它自己「学」出一个判断方法。

于是有了一个颠覆性的想法：**既然规则写不出，那就让数据「说话」——机器从大量例子里，自动找出「猫长什么样」的规律。** 这个「从数据里找规律」的过程，就是**机器学习（Machine Learning）**。它和传统算法的根本区别是：**传统算法「人给规则」，机器学习「机器学规则」。**

## 3.2 三种学法：监督、无监督、强化

机器学习按「喂给机器的答案」分三类：

- **监督学习（有答案）**：喂给机器一堆「带标签」的例子——「这张图 = 猫」「这封邮件 = 垃圾」。机器学会「看到 X，判断是 Y」。**像老师给了标准答案，学生照着学。**
- **无监督学习（没答案）**：不告诉机器答案，让它自己「找结构」——把相似的东西归成一堆。**像你自己翻一箱旧物，没人教，却自然地「分门别类」。**
- **强化学习（试错 + 奖励）**：不给标准答案，只给「做对了有糖、做错了扣分」。机器在一次次尝试里，学会「怎么做能拿更多糖」。**像训练小狗：坐下就给零食，久了它就懂了。**

其中**监督学习**是今天绝大多数 AI 的主干（认图、翻译、识别垃圾邮件都是它）。记住这三类，你就握住了「机器怎么学」的第一把钥匙：**有答案的照着学，没答案的自己归，有奖励的试错学。**

## 3.3 神经网络：模仿大脑的一层层"筛子"

机器「学」的载体，是一个模仿大脑的结构——**神经网络（Neural Network）**。

它由一个个「神经元」组成。一个神经元干的活极其简单：**把收到的信号，各自乘一个权重，加起来，再过一个「开关」决定要不要往外传。**

```
一个神经元的计算：
  y = σ( w₁·x₁ + w₂·x₂ + ... + b )
      ↑                      ↑
   激活函数（开关）      加权求和
```

- **权重 w**：每个输入「多重要」——这就是机器要「学」的东西。
- **激活函数 σ**：一个「开关」，决定这个神经元「激活」还是「沉默」（模拟大脑神经元的「兴奋/抑制」）。

**单看一个神经元，笨得可怜；但成千上万个叠成一层层，就发生了奇迹。** 认出「猫」，是这样一层层「提特征」的：

- 第一层：只认出「边、角、颜色块」这些最原始的东西；
- 中间层：把边角拼成「眼睛、耳朵、毛」这些局部形状；
- 高层：把局部拼成「这是一只猫」的整体判断。

**像一条流水线，每一层干一小步，层层递进，最后「拼」出一个判断。** 这不是「某个神经元聪明」，而是「层层分工」——简单的零件，靠数量和组织，堆出了复杂的智能。

## 3.4 学习怎么发生：梯度下降

网络有了，但「权重 w」一开始是随便乱填的，认什么都错。**「学」，就是不断调这些 w，让判断越来越准。**

怎么调？核心只有一条：**让「预测和答案的差距」越来越小。** 这个差距有个名字，叫**损失（loss）**。

- 机器预测「是猫的概率 0.3」，正确答案是「猫」——差距很大，损失很大。
- 于是它算一算：**把每个 w 往哪个方向、调多大，能让损失变小一点？**
- 调完再预测，再算损失，再调……**像蒙着眼下山：看不见路，但每一步都往「脚下最陡的下坡」迈，终会走到谷底。**

这个「沿最陡的下坡一点点走」的方法，就是**梯度下降（Gradient Descent）**。

**回收一下全书：「差距变小」的过程，其实用的就是「变化率」的直觉**——2-04 函数的「坡度」、5-01 物理的「速度」、5-03 经济的「边际」，都是「变一点会带来什么」的同一种思想。**梯度下降，就是把「变化率」用在了「让机器变聪明」上：每走一步，都顺着「让错误变小」的那个方向。**

```
循环很多很多次：
  预测 = 网络(输入)              # 机器现在怎么判断
  损失 = |预测 - 答案|            # 差多少
  算梯度 = 损失对每个 w 的坡度    # 往哪调、调多大
  w = w - 学习率 × 梯度          # 沿下坡挪一小步
直到 损失 小到足够
```

## 3.5 为什么产生了智能：从概率到判断

很多人问：这一堆「加权求和 + 下山」的算术，怎么就变成「智能」了？

答案是：**AI 做的，本质是「算概率」。** 回收 5-04 概率章——机器不是「确定地知道」图里是猫，而是输出**「是猫的概率 0.97」**。它不「确定」，它「很有把握地猜」。

- **认图**：输出「猫 0.97 / 狗 0.02 / 其他 0.01」。
- **下棋**：AlphaGo 评估「这步棋的胜率是多少」，再配合搜索，挑胜率最高的走。
- **翻译**：输出「下一句最可能是哪个意思」的概率分布。

**所以「智能」的真相，是「在大量数据里学出来的、非常准的概率判断」。** 它没有「理解」图里的猫是什么，它只是发现「长这样的像素组合，标签是猫的概率极高」。**这份「从数据里熬出来的概率直觉」，让机器做出了看似「聪明」的判断。** 这不是魔法，是「数据 + 权重 + 梯度下降」反复循环的结果。

## 3.6 生成式 AI 与 LLM：会写字的机器

最近火遍全球的 ChatGPT 这类**大语言模型（LLM）**，原理可以用一句话说清：

> **它读遍了海量文本，学会了「给定前面的话，下一个词最可能是什么」。**

- **学习**：喂给它天文数字的文字，让它反复练习「补全下一个词」，直到它的「猜词能力」准到惊人。
- **生成**：你给它一句话，它**一个字一个字地「接龙」**——每写一个字，都是「算一算：下一个字最可能是哪个」，然后选一个写上去，再接着猜下一个。

```
你问：「猫有___」
模型算：下一个词的概率是
  「耳朵」 0.6  「尾巴」 0.3  「翅膀」 0.001 ...
选「耳朵」→ 变成「猫有耳朵」，再继续猜下一个……
```

它写出来的每个字，都是「概率上最顺」的那个字——**所以它说的话总是那么通顺。** 但也正因为「追求通顺」，它有时会一本正经地编出**根本不存在的事实**（行话叫「幻觉」）。**「编得通顺」和「说得对」是两回事**——LLM 擅长前者，不保证后者。用它的正确姿势是：**当它是一个「超级流畅的初稿机器」或「陪你想点子的助手」，而不是「永远不会错的答案库」。**

## 3.7 AI 的边界：它会"想"吗？

回到本章开头的那个问题。AI 会算概率、会找规律、会模仿语言——**但它到底会不会「想」？** 诚实的回答是：

- **它会**：在数据里找规律、做概率判断、生成流畅的文字。这些它做得比人快得多。
- **它不会**：真正「理解」它说的意思、保证每句话都对、做真正的因果推理（回收 5-04 概率章的「相关 ≠ 因果」）。

**一句话：AI 是「极其强大的规律模仿者」，不是「有意识的理解者」。** 它写「我理解你的感受」，只是因为它读过无数人这么说，算出了「这个场景下，人们最常说这句话」——而不是它真的「感受」到了什么。

这个边界，和上一章 2.8 的「计算边界」是一脉相承的：**机器的能力，建立在一层层数学（概率、优化、搜索）之上；数学能到哪，机器就到哪。** 它不是万能的，它的「聪明」有清晰的来历，也有清晰的限度。

## 3.8 AI 能做什么、怎么用

落到「如何使用」，AI 现在最靠谱的用武之地：

- **做「重复 + 规律」的活**：写格式固定的报告、翻译、总结长文、找 bug、生成代码草稿。
- **做「海量」的活**：一秒扫几万张图、分析几千万条评论、从大海捞针。
- **做「初稿」**：给一个还不完美、但能改的起点，人再判断、修正、负责。

**它取代的，是「重复」和「规律」；它取代不了的，是「理解」「判断」「负责」和「真正创造」。** 所以面对 AI，最好的态度不是恐惧也不是神化，而是：**把它当成一个「又快又博学、但会偶尔胡说」的助手**——它出初稿，你来做判断、把关、负责任。**真正值钱的，从「会算」变成了「会判断」。**

## 误区（本局小结）

1. **「AI 像人一样会思考」** —— 最大的误区。它是「规律模仿者 + 概率判断者」，不是「有意识的理解者」。拟人化是理解 AI 最大的障碍。
2. **「AI 说的流畅，就一定对」** —— 错。LLM 追求「通顺」，会一本正经地编造事实（幻觉）。**流畅 ≠ 正确。**
3. **「AI 是魔法 / 黑箱」** —— 不是，是「数据 + 权重 + 梯度下降 + 概率」的层层算术。每一层都能拆开看。
4. **「AI 会取代一切」** —— 它取代「重复 + 规律」，取代不了「理解 + 判断 + 负责 + 真正的创造」。
5. **「神经网络真的像大脑」** —— 只是「受了启发」的极简模仿，和真实大脑差得极远。别把比喻当事实。
6. **「机器学一下就会了」** —— 背后是海量数据 + 天文数字的计算。它「学得快」，是因为吃了「几百万份作业」。
