# 0-01 符号从哪里来

> 数学是一座楼，第〇部分是"灰浆"——符号。灰浆看起来朴素，但它决定砖墙能不能咬合。这一章不讲"符号什么意思"，先讲"符号为什么长这样"。读者会发现：几乎所有数学符号都是**笨拙工具的幸存者**，没有一个是被天才凭空设计的。它们是几百年来无数双手，为了"写起来省事一点、讲起来清楚一点"，一点点磨出来的。读这一章，你会先和数学"握手"——它不神秘，它只是有点旧。

---

## 1.1 数字的故事：0 的迟到与发明

人类计数比写字早得多。绳子打个结，石头码成一堆，骨头上刻几道痕，都是计数。一只羊刻一道痕，两只羊刻两道——这套办法今天在牧民和渔夫手里还在用，它管用，但它有一个致命的局限：**它只能"记录"，不能"计算"。**

为什么？因为那些都不是"数字"，而是"记号"。记号是临摹：三只羊，就摆三个石子，一对一，谁也不抽象。你要做的算术题是"三只羊加上两只羊"，记号法只能摆两堆再数一遍。它没有把"三"从"三只羊"里抽出来。

真正的突破，发生在"数"与"被数的东西"**脱离**的那一刻：我们不再画三个桔子，而是写一个"3"。这个"3"既能表示三筐桔子，也能表示三个下午、三声心跳、三次台风。一旦"三"能被单独拎出来当东西摆弄，"算"这件事才真正开始。

这个脱离有个响亮的名字，叫**位值制**。位值制的意思是：同样一个数字，站在不同位置，值就不同。5 在个位是五，在十位是五十，在千位是五千——同一个"5"，身价全由它站的位置决定。

要体会位值制有多厉害，看一个反例就够了：**罗马数字**。罗马人写 12 是 XII，写 13 是 XIII，看着都挺清楚。但请你用罗马数字做一道乘法：12 × 13 = ? 把 XII 乘以 XIII——你会立刻发现，这套写法里"位置"不值钱，每个字母只代表它自己，于是**没法列竖式、没法进位、没法心算**。中世纪欧洲的商人被迫用算盘摆珠子来绕开这个坎。这正是位值制的伟大之处：它把"多位数"拆成"几个单数 × 它们的位置"，让"列竖式"成为可能。我们今天觉得 123 + 456 天经地义，是因为位值制已经把重活替我们干完了。

但位值制有个要命的技术难题：**"一百零三"和"一千零三"怎么区分？** 你写 103 和 1003——中间那个空出来的位置，必须有一个符号去"顶住"它。否则 103 与 13 无法分辨，1003 和 13 也无法分辨。"空位"不能真的空着，得有个东西坐在那儿，说一句："这里没有数，但我守着这个坑。"

这个"顶住位置的符号"，就是 0。

**0 的迟到，是数学史上最著名的一次迟到。** 各文明先后撞上这道难题，各想各的办法：

- 苏美尔人（两河流域）最先遇到它，他们的做法是**空一格**——物理上留个空档。但空格会在抄写时被误读、被吃掉，"空"毕竟不是一个能摸到的字符。
- 玛雅人独立发明了类似贝壳的符号，专门用来占位，比欧洲早了一千多年。
- 而把 0 从"占位的空档"**扶正成一个真正的数**（能运算、能相加减、能被别的数减掉），公认的功劳记在印度人账上。公元 7 世纪的印度数学家梵婆塔（Brahmagupta）已经写下了现在仍成立的核心规则：0 加任何数还是那个数，0 减任何数得负数。（这位先驱也在 0 上栽过一个跟头：他规定 0÷0=0，今天我们才知道这恰恰是"无法定义"的雷区——见 1-01 的误区。）

0 从"占位符"升格为"数"，这一小步极其昂贵：在许多人眼里，"没有"怎么还能是一个"东西"？一个空圈，怎么就配住进账本、参与运算？中世纪欧洲的会计甚至拒绝使用 0，理由是它"长得像一个空圈，是空的，怎么能入住账本"。今天我们用起来毫无感觉的"0 是自然数吗"这个疑问，正是这场千年官司的回声——它会出现在（第一部分·1-01 数系大厦）的误区里。

> 一句话记住本章 1.1：**没有 0，就没有位值制；没有位值制，就没有现代算术。0 是个"占位符"起家的数，从"顶坑的记号"熬成了"真正的公民"。**

反着想想更有意思：既然 0 是为位值制发明的，那么**只需要两个数字的进位制**（二进制），0 和 1 一起出马，就能写出所有整数——这是（第一部分·1-03 进制）要讲的事。你现在手里这个能显示文字的设备，里面跑的全是 0 和 1 两位演员的对手戏。

## 1.2 运算符号的来历：＋－×÷＝

今人把 ＋－×÷＝ 当作天经地义的"天生符号"，其实它们大多是中世纪抄书匠的**速记缩略**，各自有一段出身不太体面的履历。它们没有一个是数学家坐在书房里"设计"出来的，多半是"写着写着就顺手简化了"。

- **＋（加号）。** 拉丁文里"两个数和在一起"的连词是 *et*（相当于英文的 "and"）。中世纪的抄写员嫌写全太慢，把 et 两个字母连笔草成一个横着的叉，很快就演化成今天的"＋"。所以加号本来是个"and"——它字面上的意思是"把 3 和 5 放在一起"。你看，加法从一开始就是"并"，不是"变"。
- **－（减号）。** 比加号更早的说法是：减号本是拉丁 *minus*（"少"）的缩写 m，写着写着横写掉了一条腿，只剩下那道横线。也有人主张它来自天平：把东西取走，托盘下沉——一道横线记录了"从满载里拿走"的痕迹。两种说法都指向同一件事：**减号从一开始就贴着"拿走"的意思。**
- **＝（等号）。** 这是少数有明确"出生证"的符号。1557 年，英国数学家罗伯特·雷科德（Robert Recorde）在书里写下了一句至今被人引用的话："为了避免日复一日地重复'这两者相等'这句话，我准备用两条平行的线段来做记号——因为没有什么比两条长度相同的线更相等的了。"你看，等号连形状都是有道理的：两条线一样长，所以"相等"。
- **×（乘号）。** 1631 年，英国数学家奥特雷德（William Oughtred）把斜轧的"×"当作乘法的速记。理由是牵强的：十字相撮表示"交织"。讲数学史的人常忍不住调侃：他也许只是怕和学生撞车，因为别人已经占用了"＋"。注意：**× 后来还被人借去表示"叉积"**——同一个抄写的故事，在（0-03 容易混淆的符号对）和（第四部分·4-05 向量）会再见。
- **÷（除号）。** 是瑞士人拉恩（Johann Rahn）1659 年的作品，短横上下各加一点：横线之上甲、之下乙，标出"甲被乙分"。至于我们更熟悉的另一种写法——分数中间那条"横线"，它和 ÷ 的关系，正是你点名要辨清的（0-03.3）。

有没有觉得这套历史很"手工作坊"？对。数学符号几乎全部经历了"先约定俗成、再被标准局追认"的过程，没有一个符号从发明那天起就拥有今天的地位。

这里藏着一个容易被忽略、却极其重要的问题：**符号化本身，就是一场革命。** 想象一下没有符号的数学。中世纪欧洲人算"三分之二加四分之一"，得用拉丁文写一整句："取三分之二，再加上四分之一，求其和"——一页纸写不了几道题，思路全被文字淹没了。符号把这一整句压成 `2/3 + 1/4`，眼睛一扫，结构一目了然。**符号不只是省纸，它改变了一个人思考数学的方式**：当算式短到能一眼看尽，你才能腾出脑子去想"接下来怎么变"。所以说，符号是数学的"脚手架"——它不负责盖楼，但没有它，楼根本盖不高。

这是理解数学的第一个好性子：**符号是人造的、会被改的、可替代的；符号是衣裳，不是骨架。** 真正不可替代的是背后的想法。

## 1.3 未知数为什么叫 x

这是每本数学史书都要讲一次的动人故事。

公元九世纪，阿拉伯学者花拉子米（al-Khwarizmi）写出了《代数学》（al-jabr），书名的字根 al-jabr（"复原""移项"）后来演变成西方的 *algebra* 一词——今天说的"代数"这个名字，是给这本书的致敬。书中把未知数唤作 **al-shalan，意思是"事情本身"**——你要找的那个数，不是某个具体形状，而是"这东西就是这东西，我们且叫它'那件事'"。这个叫法有种朴素的美：**未知数没有被当成一个谜，而是被当成一件"待认领的事"。**

当这部书横渡地中海进入西班牙和西欧时，翻译家碰到了一个老难题：阿拉伯字母里有些音，拉丁字母里没有对应。al-shalan 原可以写作希腊字母 χ（khi），而对不懂希腊文的抄写员来说，χ 长得太像拉丁字母 x 了。于是，**"事情本身"这个词，漂洋过海后穿着拉丁字母 x 的马甲上岸。** 一传十，十传百，x 就成了那个"不说名字却能算账的家伙"。

（另一种更朴素的传说：笛卡尔在《几何学》里约定用 a、b、c 表示已知量，用 x、y、z 表示未知量，只是因为印刷厂 x 的铅字最充裕。两种说法并存，选你爱信的那一种——它们都说明同一件事：**x 并不天生神圣，它是"占个名字"的临时工，上岗三百年后成了固定职业。**）

而且这一章值得记住一个衍生事实：语文里的"X 先生""X 档案""不明物体用 X 命名"，全部来自同一个词源——"待定的东西"。数学符号溢出了数学，变成了全人类"未知"的公共记号。你在侦探片里看到的"某嫌疑犯 X"，和代数卷子上的"求 x"，用的是同一个字、同一种心态：**先给它一个名字，再想办法把它揪出来。**

## 误区

1. **「数字」和「符号」是一回事。** 不是。数字是"数"的书写工具，符号是"运算/关系"的书写工具。有人说"0 这个数字很普通"，其实是在批一件外套——外套普通不普通，和穿它的人（数）无关。混淆这两者，就像把"演员"和"演员的戏服"当成同一个东西。
2. **「数学符号是先天设计好的」** 错。＋本想写 "and"，＝是嫌累的抱怨，x 是翻译的误会——它们全是手工作坊的幸存者。没有哪个符号从娘胎里就长今天这样；它们是被"用"出来的，不是被"想"出来的。
3. **「没有 0 顶多是不方便」** 错。没有 0，位值制就无法稳定工作，"103"会与"13"混淆，"1003"也会与"13"混淆，现代算术的写法就建立不起来。0 不是锦上添花，是地基里的一根承重桩。
4. **「印在书里的符号不会改变」** 错。数学符号在几百年里一直在被替换、被占位、被抢注（想想 ×）。符号可以换，思想不能换——这是全书的基调之一。别对符号"认死理"，要认清符号背后站着的那件事。
5. **「符号越简洁，数学就越简单」** 半对。简洁的符号确实让算式一眼看尽，但简洁本身不是目的——**看得清结构**才是。有时候一个符号（比如分数线）会偷偷"藏"起括号，简洁反而埋了坑（见 0-03.3）。符号的简洁，永远以"不引起歧义"为底线。
