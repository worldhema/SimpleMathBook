# 4-04 极坐标系：距离 + 角度

> 直角坐标系（4-01）用"两个垂直方向"描述位置——往右多少、往上多少。但有些问题（旋转、圆、螺线、雷达），"两个垂直方向"反而是最绕的说法。**极坐标系**换一种问法：**离原点多远？朝哪个方向？** 它用"距离 + 角度"描述位置，是"直角坐标"的旋转友好版，也是复数章（1-07）"模与辐角"的正式还魂。

---

## 4.1 极坐标：r 和 θ，两个数定一个点

极坐标系里，一个点用一对数 (r, θ) 描述：

- **r（极径）**：到原点（极点）的距离。
- **θ（极角）**：与正 x 轴方向的夹角（通常用弧度，4-02）。

直角坐标 (x, y) 与极坐标 (r, θ) 可以互相翻译（用三角函数，4-03）：

$$
x = r\cos\theta, \qquad y = r\sin\theta
$$

$$
r = \sqrt{x^2 + y^2}, \qquad \tan\theta = y/x
$$

**哪个好用？** 看问题：
- 直来直去、横平竖直的问题（画矩形、算斜率）→ 直角坐标。
- 旋转、以某点为中心的问题（圆、螺线、雷达扫描）→ 极坐标。

**同一个点，两套住址**——就像同一个地点，既有门牌号（直角），也有经纬度（极）。哪套顺手指哪套，翻译随时可做。

## 4.2 极坐标与圆、螺线：旋转世界的母语

极坐标的爽点，是"以旋转为中心"的形状写起来特别干净：

- **圆（圆心在原点）**：r = 常数（半径）。极坐标里一个"r=3"就描述整个圆，直角坐标要写 x²+y²=9。
- **螺线**：r = aθ（θ 越大，r 越大）——阿基米德螺线，像卷起来的弹簧。直角坐标写它几乎不可能，极坐标一句话。
- **心脏线（心形线）**：r = a(1+cosθ)……这些"花瓣""爱心""漩涡"的曲线，全是极坐标的招牌菜。

**一句话**：**极坐标把"离中心多远"和"转了多大角"分开记账**，所以凡是"围绕一个中心转"的形状，它就是母语。

## 4.3 极坐标 = 复数的模＋辐角（与 1-07 联姻）

回访 1-07.4 的伏笔：复数 z = a + bi 有**直角式**（a, b 是横纵坐标）和**极式**（模 |z| + 辐角 θ）。现在可以说透：

> **复数 = 平面上的点，而极坐标正好给这个点两套坐标。复数的模就是极径 r，复数的辐角就是极角 θ。**

```
z = a + bi     （直角式：横坐标 a、纵坐标 b）
  = r(cosθ + i·sinθ)   （极式：r = |z|，θ = 辐角）
```

这个"复数 ↔ 极坐标"的接吻，价值惊人：

- 复数乘法（1-07.4：模相乘、辐角相加）在极式里一目了然：
  - 把 r₁(cosθ₁+isinθ₁) 乘 r₂(cosθ₂+isinθ₂)，结果是 r₁r₂(cos(θ₁+θ₂)+isin(θ₁+θ₂))——**模乘、角加**。
- **"乘法 = 缩放 + 旋转"**：一个复数乘另一个复数，等价于"把长度按 r 缩放，再旋转 θ 角"。这正是向量旋转、图像变换（2-06 矩阵的几何变换）在复数世界的镜像。

**这条联姻是 4-06 欧拉公式的直接入口**——下一章的主角"复数指数"，就是在这里和"旋转"焊死的。

## 误区（本局小结）

1. **极坐标是"另一种坐标系统"** —— 是同一平面的另一种描述法，与直角坐标互相可翻译。
2. **r 一定是正数** —— 常见取 r≥0，但允许 r<0 时表示"反方向转"（数学上合法）。
3. **极坐标只是"画图形用"** —— 它是复数（模+辐角）、雷达、导航、物理角运动的母语。
4. **直角坐标"更正确"** —— 都只是"顺手的坐标系"，选哪套看问题，翻译随时可做。
5. **复数乘法靠背规则** —— 极式里"模乘、角加"是天生的，不用背。
