# 0-02 符号大观

> 上一章讲了符号的来历（0-01），这一章给符号上"户口"。我们按"它们各管哪片地界"分类兜一遍：运算符号管"算"，关系符号管"比"，特殊符号管"度量和集合"，希腊字母管"排队命名"。不需要背——它们是观赏目录，写到哪一章用到再回头查。

## 2.1 运算符号：算这件事的四组演员

算术的四个基本动作——加、减、乘、除——符号已经见过（0-01）。这里补充它们的老兄弟：

- **幂**：写在上标的右上角小字，如 3² 里的 2，表示"连乘自己几次"。上标的位置本身就是一个符号——位置和符号打架的地方，正是（第二部分·2-02 幂与指数）的重头戏。
- **点乘 ·**：物理和线性代数里，"·"常替"×"表示乘（也指向量点积，第四部分·4-05）。同一个点两种称呼，一件事要说三遍——符号界最繁忙的临时工。
- **分数线／**：甲写在横线上、乙写在线下，就是分数。它实际是"除法"的另一种写法（0-03.3 专门辨清）。

## 2.2 关系符号：比大小的全部词表

- ＜ 小于，＞ 大于——尖角永远指向"更小的一侧"，这是全人类记忆它们的唯一技巧。
- ≤ 小于等于，≥ 大于等于——把等号借来垫在下面，含义一目了然。
- ≈ 约等于：表示"足够接近"。什么时候算"足够"？取决于问题——这正是（2-05 方程）里"近似解"的话题。
- ≠ 不等于。
- ≡ 恒等：左右两边"怎么都相等"，不仅仅是"这一次相等"。x 与 x 之间恒等，3 与 3 之间也恒等，但"这一份是那份"的同一性检验有个迷人的歧义——（0-03.5）会把这个家族整体梳理一遍。
- ＝ 相等。本符号的几副面孔集中在 0-03.5。

一个提醒：这本书里凡是"约"字开头（≈、约等于、roughly），等于写了一行免责声明：**数学允许"够用就好"，只是要明白"够用"的标准由谁定。**

## 2.3 特殊符号：√、∑、∏、!、∞、|·|、∈

这些符号各有专职，先混个脸熟，不必背定义：

- **√（根号）**：拉丁词 radix（根）的 r 演变的遗形。√4 该取正还是负，是全书写给读者的第一个"陷阱级"分岔——0-03.6 当堂拆解。
- **∑（求和）**：希腊字母的"大写 Σ"（sigma），就是把一串数加起来的意思。它在数列章（1-05）真正上岗，作用是"把'从第1项加到第 n 项'这句中文压成一个符号"。
- **∏（连乘）**：大写的希腊字母 π（pi）旋转成直角，是"把一串数乘起来"。注意：连乘符号 ∏ 和圆周率 π 是同一个字母的两个神态，别被外表唬住。
- **!（阶乘）**：n! 表示 1×2×3×…×n，读作"n 的阶乘"。它出现在排列组合（5-05），意思是"把这些东西排队一共有多少种排法"。
- **∞（无穷，读作"无穷大"）**：一个被美化成"横在海上的 8"的符号，第 1-02 章会严肃处理它的身份问题——**它到底是不是一个数？** 提前剧透：不是。
- **|·|（绝对值）**：竖杠包住一个数，表示"它到 0 的距离"，所以 |−3|=3。到了复数章（1-07），这个杠会升级成"模"，管的是"离原点多远"。
- **∈ ⊂ ∪ ∩**：集合的四大金刚——"属于""包含""并""交"。第 1-02 章 一次性讲透。

> 口诀：**这些特殊符号全都不是新运算，是"省口舌"的速记。** 数学家不是嫌符号多，是嫌中文句子长。

## 2.4 希腊字母表：数学的"二外来语言"

拉丁字母（a、b、c…z）只有 26 个，工程师和科学家很快用完了。于是数学从希腊语里借来一整副字母，给"后排观众"编号。下表只列真正常用的七个：

| 大写 | 小写 | 读法 | 在本书中的角色 |
|---|---|---|---|
| Γ | γ | gamma | 欧拉常数 γ（1-06 出场，一个"很像超越数但没人证明"的家伙） |
| Σ | σ | sigma | 求和 ∑（1-05） / 标准差 σ（5-05） |
| Π | π | pi | 圆周率 π（3-05、1-06） |
| Φ | φ | phi | 黄金比 φ（1-05） |
| Ω | ω | omega | 角频率 ω（5-01 物理，越快越紧张） |
| Δ | δ | delta | 变化量 Δx（"变了多少"）（5-03 经济） |
| Θ | θ | theta | 角 θ，弧度的主人（4-02） |

希腊字母还有一个深远作用：**它是数学的"外号系统"。** 同一个希腊字母兼任好几个职务时（比如 σ 既当求和又当标准差），上帝很生气，数学却很平静——反正可以有上标下标州区。

## 2.5 数学里的字母分工：谁站队，谁当主角

一篇数学文章里，字母早有暗号：

- **a、b、c 常是已知的常量**（常数），罗马的"已给的"。
- **x、y、z 常是未知/变量**，要去找的"事情本身"（0-01.3）。
- 真正的大明星专职专座：
  - **i**：虚数单位，i²=−1（1-07 连续三章招待它）。
  - **π**：圆对直径的比值，超越数（3-05 出场，1-06 深谈）。
  - **e**：自然增长的底，超越数（2-03 定义完整，1-06 深谈）。
  - **g**：重力加速度（5-01）。
  - **θ、λ、μ**：角、波长、平均——物理侦察员。

记忆法：**常量站 a、b、c 台，变量站 x、y、z 台，主角（i、π、e）有自己的专属化妆间。**

## 误区

1. **「用∣·∣包住的数总是正数」** 对了一半——|x| 是"到 0 的距离"，x 若为负，结果与它"相反"，但结果始终是非负。确切说：|x| 永不小于 0。
2. **「∑ 和 ∏ 是新运算」** 不是，只是"连写一堆加/乘"的缩写，是省纸工程。
3. **「∞ 是最大的数」** 这是全书写的最凶的一道误区——∞ 不是数，详见（1-02 集合与无穷）。
4. **「同一个希腊字母出现在两个地方，肯定有联系」** 不一定。Σ=求和、σ=标准差，只是字母重名，如同"张"字用在两个人名里。
5. **「i 是"想象的"，不真实」** 虚数的"虚"是翻译悖论（1-07），i 是这本书要替它翻案的主角。
