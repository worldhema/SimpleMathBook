# 1-05 数列：排成一行的数

> 数系大厦（1-01）里，数们安静地站在数轴上各居其位。这一章的场面不一样：**数开始排队。** 队伍也有学问——有的队伍整整齐齐（等差数列），有的队伍越走越快（等比），有的队伍藏着黄金比例的密码（斐波那契），还有一支队伍走向一个惊人的结论（调和级数）。

---

## 5.1 数列是什么：排成一行的函数

**数列（sequence）**：按顺序写出来的一串数——第 1 项、第 2 项、第 3 项……

- 记法：a₁, a₂, a₃, …，读作"a 一、a 二、a 三"。
- 数列的核心是一个**规则**：给定序号 n，如何得到第 n 项的值 aₙ。

看规则，一眼就认出老朋友：
- aₙ = n 表示数列 1, 2, 3, 4…（自然数）。
- aₙ = 2n 表示 2, 4, 6, 8…（偶数）。

**要害：数列本质是一个"函数"，它的自变量是"第几项"这个序号。** 上一章承诺的"函数与数列的关系"在这一句兑现：函数是把一个数映射到另一个数（2-04 会正式上场）；数列是"**把'第几项'这个整数下标映射到数值**"的函数。所以数列是函数的"排队版"，函数是数列的"漂浮版"。从现在起，见到"第 n 项"，心中默念 **n ↦ aₙ**。

用一个具体的动作感受一下：aₙ = 2n+1 这个规则，你问"第 1 项是几"，它答"3"；问"第 100 项是几"，它答"201"。**你输入序号，它吐出数值**——这不就是一台机器吗？数列和函数唯一的差别，只是它这台机器只收"整数"当输入。所以说"数列是排成一行的函数"，一点也不夸张。

问题来了：为什么要排队？

- **求和**（下面的 5.4）只有在"队"里才有意义——把一串数加起来。
- **趋势**（5.5）只有顺着"队"的走向才能看出"往哪去"——这通向本书最深的洞：极限。

## 5.2 等差与等比：两支基础队伍

**等差数列**：每相邻两项的**差**相同。
- 例子：2, 5, 8, 11, …（每次 +3）。
- 第 n 项：aₙ = a₁ + (n−1)d。

**等比数列**：每相邻两项的**比**相同。
- 例子：3, 6, 12, 24, …（每次 ×2）。
- 第 n 项：aₙ = a₁·rⁿ⁻¹。

两者气质迥异，是全书第一组"性格对照"：

- 等差是"匀速"，像信步——每天多存 3 块。
- 等比是"倍增"，像滚雪球——人数传染、贷款利滚利、储蓄复利。**等比数列增长的可怕速度**（翻一倍只需翻一番的时间），到（5-03 经济学）的复利章会做现场表演。
- 直觉陷阱：**差与比的区别，是人类最常把"百分比增长"当"线性增长"的思维习惯**——"每年涨 5%"不是"每年加 5 块"。

这个"性格对照"值得用一个例子钉死。假设你月薪 1 万，有两种涨法：**方案 A 每年固定加 1000 元**（等差）；**方案 B 每年涨 5%**（等比）。头几年 A 涨得快——第 2 年 A 是 11000，B 是 10500。但十年后，A 是 20000，B 已经是 1×1.05¹⁰≈16289；二十年后 A 是 30000，B 已经超过 26500；再往后，B 会把 A 甩得看不见尾灯。**等差是直线，等比是曲线，曲线一开始输，后程必然翻盘。** 这就是为什么"复利是世界第八大奇迹"——它不是快，是"越来越快"。

## 5.3 斐波那契与黄金比 φ

排队的队伍中，最迷人的一支不是等差也不是等比，是斐波那契（Fibonacci）：

> 从 1 开始，之后每一项都是前两项之和：1, 1, 2, 3, 5, 8, 13, 21, 34…（aₙ = aₙ₋₁ + aₙ₋₂）

为什么迷人？

- **它长在自然界**：向日葵籽的螺旋、蜂巢的计数、兔子繁殖的寓言（斐波那契本人的原作正是个兔子问题），都能在这支队伍里找到影子。自然界并不"知道"这个数列，它只是反复"前两项合成下一项"这个规则（再如树叶的排布节律），凑出同一支队伍。
- **它与黄金比 φ 私通**：随便取相邻两项求比值，5/8、8/13、13/21、21/34……你会发现这个比值飞快地**越来越接近 0.618**，也就是
  $$
  \varphi = \frac{1+\sqrt{5}}{2} \approx 1.618
  $$
  （一般记 φ=1.618，它的倒数≈0.618）。这个数在艺术、建筑、几何里到处客串（第 5-05 艺术章会回收）。

> **为什么比值会"飘进"φ？** 假设稳定比值存在，设相邻两项之比趋近某个 r，那么 aₙ = aₙ₋₁ + aₙ₋₂ 两端除以 aₙ₋₁ 得"r ≈ 1 + 1/r"，解出的正根正是 φ。一大堆惊艳，背后一条代数。数学的"美"往往就是这样：**先被惊艳，后见真容——真容是代数。**

## 5.4 求和：∑ 正式上岗

把数列的前 n 项加起来，记作：

$$ a_1 + a_2 + \cdots + a_n = \sum_{k=1}^{n} a_k $$

∑（读"西格玛"，0-02.3 见过）正式上岗，把"从第 1 项加到第 n 项"这句中文压扁成一个符号。第一次见到它的读者容易吓一跳，但请记住它的本质极其朴素：**∑ 就是"把后面那一串加起来"的循环指令**，上面的上下标分别是"从哪开始、到哪结束"。

几个立刻见效的求和公式（它们会在生活章疯传）：

- 等差求和：首项+末项之和 × n/2。1+2+…+100 = (1+100)×100/2 = 5050 —— 高斯 9 岁时的传说名场面。
- 等比求和：a₁(1−rⁿ)/(1−r)。

高斯的故事值得重讲一遍，因为它是"看穿结构"的教科书：老师罚全班算 1+2+…+100，别的孩子一个个加，高斯却把首尾配对——1 配 100 得 101，2 配 99 得 101，一共 50 对，答案 5050。**他赢在不是"算得快"，而是"看见了队伍里藏着 50 对同样的 101"。** 数列求和的精髓就在这儿：别急着加，先看结构。

## 5.5 无穷之门：调和级数为什么"叛变"

读者也许已经有点飘——大不了来个"求和的级数"嘛。现在登场的是全书第一次"直觉当场翻车"的表演。

**调和级数（harmonic series）**：
$$
1 + \frac12 + \frac13 + \frac14 + \frac15 + \cdots
$$

问：这个无限长的和，是几？

直觉会说："每一项越来越小，和应该有限，可能收敛到某个数。"——**错了。这个小步向你走的东西，加起来是无穷大。**

证明的美，在于用一个柯西式的分组：

- 把级数按段分组：1 + (1/2) + (1/3+1/4) + (1/5+1/6+1/7+1/8) + …
- 每段放小：1/3+1/4 > 1/4+1/4 = 1/2；1/5+…+1/8 > 4×(1/8) = 1/2；如此分组，每一组都 ≥ 1/2。
- 于是"1 + 无限多个 1/2"——按分数加法的账，就是 ∞。

**这就是著名的调和级数发散。** 它教给读者的不是"有个反直觉的数"，而是一个 引路者——"**项变小 ≠ 和有限**"。这个反直觉将反复出现（等比 1/2ᵏ 收敛——也很有意思：每个 r<1 的等比都收敛，而调和级数"每一项 1/k"发散，才刚碰到"收敛与发散的边界"）。

仔细看这个分组有多巧妙：它不真的"算出和是多少"，而是**把每一项都往小里估，结果还能凑出无限个 1/2**。你都已经尽量"抠门"了，和还是无穷大——那真实的和当然更是无穷大。这种"故意低估、反而证明无穷"的手腕，是数学家最爱的招式：**要证明一个东西"大得离谱"，就把它往小里压，结果还是压不住。**

**理解发散的钥匙**：当级数里每一项 1/k 的规模，大得足够"撑开"每条和的底线——这就是人类第一次看清"无穷和"的极限概念在前院的影子。下一章（1-06）暂且放一放这个火种——极限的加油站（微积分）在整本书后半场。先记住一句压舱的话：**数列的终点不是某个"最后一格"，而是"往哪去的吸引子"——这就是后面会不断遇见的极限。**

## 误区（本局小结）

1. **把"第 n 项"误以为只有等差/等比两种形态** 错——斐波那契它都不是这两种，别把"数列"学成"两种模板"。
2. **"百分比增长 ≈ 线性增长"** 错——"每年 +5%"是等比（复合/复利），尾巴会甩开线性几条街。
3. **∑ 是神秘符号** 不是，它就是"从 a 加到 b"的循环指令。
4. **调和级数收敛** 错——它是发散名门，证明靠分组"每组 ≥ 1/2"。
5. **"项变小就收敛"** 错——调和级数的每项趋近 0 却仍然发散。收敛的门槛更高。
6. **φ 只在艺术里** 错——它从斐波那契的代数线性关系中长出来，艺术只是它的衣帽间。
7. **数列就是"一串数"** 太浅——它是"序号 ↦ 数值"的函数，是函数世界的排队版。
