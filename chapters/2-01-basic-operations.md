# 2-01 基础运算：加减乘除的家谱

> 算术是数学的"手工活"，但手工也有手工的哲学。这一章不只是复习"加减乘除怎么算"，而是要看清三件事：**加与减、乘与除是一家的两半（逆运算）；负数的算术有自己的一套语法；运算定律是整座算学楼的承重墙。** 你小时候背过的"负负得正"，本章给你一个终于"能听懂"的解释。

---

## 1.1 加与减：一个动作的两张脸

加法想都不用想：把两个数并在一起，3+5。减法是"拿走"。但请看这一位（0-03.2 已埋下的语法糖，现在公开全部）：

$$ 3 - 5 = 3 + (-5) $$

**减法 = "加上这个数的负数"。** 这一个改写，把"减"从"第二种运算"变成了"第一种运算的一种特殊情况"。为什么值得高兴？因为从此以后，世界上的运算不再是"加法、减法"两套，而是**一套加法 + 负号语言**。往后你看到的每一个"减"，都可以在心里默念"加负"。这是代数里第一次"语法化简"，也是"逆运算"这个概念的第一个实例：

> **逆运算 = 用一个数的"反"把它抵消。** 加的反词是加负数（b 的"反"是 −b）。"反"字的用途：3 + (−3) = 0，互为相反，互为"撤销键"。

这套"化减为加"的手法，价值远超表面。它让你把一大堆运算统一成"加法"一种语言，就像电工把千奇百怪的电路统一成"电流进出"一套语言。**统一语言，是简化思考的第一步**——往后凡是遇到"减"，你的脑子只需要启动一个程序："加上它的负数"，不用再另开一个"减法"专区。这就是为什么数学家喜欢说"只有加法，没有减法"。

## 1.2 乘与除：倍数关系，及它的"除法"

乘法是"重复加法"的缩写：4×3 就是 3+3+3+3。除法的待遇和减法一模一样：

$$ a \div b = a \times \frac{1}{b} $$

**除法 = 乘上"乙数的倒数"。** 于是世界上的运算收敛为两种：加法、乘法——减法与除法都是它们的"反动作"。这就是为什么 0-03.3 说"分数线里藏着除法（a/(b) = a ÷ b）"：它们本就是同一个动作的两件外套。

到这里，整个算术世界的骨架就清晰了：**两个基本动作（加、乘），各带一个反动作（减、除）。** 四则运算不是四兄弟，是"两对父子"。这个骨架看起来简单，却是后面一切运算的出发点——幂、开方、对数、函数，全都站在"加法和乘法"这两块地基上往上盖。

**一个立刻重要的推论（×0 的陷阱，本节压轴之一）**：
- 3 × 0 = 0：任何数乘 0 都是 0。
- 那么 3 ÷ 0 是什么？回到逆运算：a ÷ b 的定义是"找 x 使 b×x = a"。当 b=0 时，0×x 恒为 0，当 a≠0 无解，当 a=0 时"任何 x 都行"——两种情况都不能给 x 一个确定的答案。（回顾 0-03.2 说的"分母≠0"，这就是它的"为什么"，正式判词在 1-01.6 误区①。）

用一句话钉死这个"为什么"：**除法的本质是"乘法的逆运算"，而 0 作为乘数是"黑洞"——任何数进去都变成 0，信息全丢。** 信息丢了，逆运算就"回不去了"，所以"除以 0"在逻辑上无解。0 能乘（正着走可以），不能除（逆着走回不来）。这就是"0 是乘法黑洞、除法禁区"的完整含义。

## 1.3 运算定律：交换、结合、分配，三根承重墙

三根"定律"，第一学期的全部家当：

- **交换律**：a+b = b+a，a×b = b×a。**加法、乘法可以换位**。减法不行（3−5 ≠ 5−3）、除法不行（4÷2 ≠ 2÷4）。请记住：**一"开口子"就看出它俩是不是"交换"的**。
- **结合律**：(a+b)+c = a+(b+c)，(a×b)×c = a×(b×c)。**先算谁无所谓。**
- **分配律**（最厉害的一根梁）：a×(b+c) = a×b + a×c。它把乘法"渗透穿进加法"——**这是中学代数里"把括号拆开"和"提公因式"两个动作的发动机**。你要是早就背过"(a+b)(c+d)"的展开，其实背后靠的全是这根梁。

这三根墙里，**分配律是唯一一个"跨界"的**：交换律、结合律都是在"同一种运算"内部打转（加法自己换、自己结合），唯独分配律横跨了加法和乘法两界，把乘法"伸进"加法里。**正是这根跨界的梁，让代数有了"展开"和"合并"两个动作**——没有它，你连"拆括号"都不会。所以它最值得记住：它是"乘法穿过加法的通行证"。

**递推的现实感**：盖楼可以混乱次序；运算只要"交换+结合"合法，怎么加怎么乘都得同一个答案——这就是为什么"先乘除后加减"这个口诀存在。它只是**一个约定**（不是数学定理）——把括号省掉的时候，全靠"先算谁"的约定稳住意思。

## 1.4 误区专场：负负得正，是什么的魔力

这是无数人对数学"半懂半不懂"的第一道坎：**(−1)×(−1) 为什么等于 1？** 给你三种视角，总有一种让你满意：

1. **向量视角（最直观）**："相乘"就是"按倍数拉伸并入旋转"。×(−1) 的意思是"转 180°"。转两次 180°= 转 360°，回到原样——所以 (−1)×(−1)=+1。（旋转和负数在 4-05 向量那里正式结成亲家；这里先种下。）
2. **账单视角（最日常）**：−3 表示"欠 3 块"。欠 3 倍的债（×3）是欠 9 块（−9）；但是"撤掉这堆债"（×(−1)）反而变成 +9——**撤债是与欠债相反的动作，撤债×欠债 = 有**。
3. **代数视角（最扎实）**：分配律 + 0 的性质推到底：(−1)×(1 + (−1)) = (−1)×0 = 0，先把括号打开：(−1)×1 + (−1)×(−1) = 0，于是 −1 + (−1)² = 0，移项得 (−1)² = 1。

第三种值得单独放大，因为它是"负负得正"的**正式身份**：它不是被"规定"出来的，而是被"逼"出来的。我们想让分配律对负数也成立（否则代数就散架了），而分配律一旦成立，(−1)×(−1) 就必须等于 1，**没有第二种选择**。所以"负负得正"不是数学家拍脑袋定的规矩，是"为了保住分配律"而不得不接受的结果。**数学里的很多"怪规则"，拆开看都是"为了不让更重要的规则崩掉"。**

**再答一个经典坑（a+b)²：**

$$ (a+b)^2 = a^2 + 2ab + b^2 $$

为什么要讲它？因为初学"分配律"的人十有八九会发出"应该就 a²+b²" 的天真恻隐。展开给你看：把 (a+b)(a+b) 拆成 a×(a+b) + b×(a+b) = a²+ab + ba+b² = a²+2ab+b²（中间那 2ab 是"交叉项"）。**字母相撞产生"交叉项"，这就是根号为什么有±、二次为什么有判别式的一个幕后角色**（2-05 见）。

## 误区（本局小结）

1. **减法是有别于加法的"第二种运算"** —— 不，减法=加相反数；除法=乘倒数。世界只有两套核心运算：加、乘。
2. **×0 是合法的？** 合法；**÷0 永远不合法**——因为"乘 0 的逆运算"无意义。0 是乘法上的"黑洞"。
3. **负负得正是否定的"凭空魔法"** —— 有分配律+0 给的证明，也有旋转和撤债的直觉。它其实是"为了保住分配律"而被迫成立的结论。
4. **(a+b)² = a²+b²** —— 错！漏了交叉项 2ab。这是"漏交叉项"家族的第一个（sin(x+y) 也是，见 4-03）。
5. **"先乘除后加减"是数学定律** —— 是约定，不是定理，目的是省括号。
6. **交换律对一切运算都成立** —— 错，减法、除法、以及后文的矩阵乘法都不满足。每条运算的"脾气"要逐个检查。
