# 1-03 进制：怎样把数写下来

> 数系大厦盖好了楼身（1-01），集合教会我们把数排好队（1-02）。这一章解决一个更朴素的问题：**数到底用什么方式写在纸上？** 你从小写 10 写 100，觉得这是天经地义——但 "10" 只是"一打写成这样"的一种约定，别的地方完全可以达成别的约定。这个世界里，至少同时存在着两套主流写法：人类的手指选出来的十进制，和计算机用电路选出来的二进制。

---

## 3.1 十进制：为什么偏偏是 10

人类绝大多数文明都选了 **10**，原因朴素得不需要考证：**我们有十根手指。** 数数时手指头是现成的计数器。

十进制的真名叫 **进位制（positional / base system）**，它的灵魂是"位置"：

- 每一位都有一个"位值"：个位是 10⁰，十位是 10¹，百位是 10²……
- 数字 10 本身不用发明——它是"个位满了进位"之后，用"1"顶到十位"代表"的结果：**10 = 1×10¹ + 0×10⁰**。

位值制（0-01.1 已埋下）意味着两件事：

1. **数字的数量不随数的大小增加。** 数到一万亿，仍然只用到 0~9 这十张牌，只是位数变长。
2. **小数的记号也统一了。** 0.25 的意思是 2×10⁻¹ + 5×10⁻²，小数点标出"负次方从哪儿开始"。

为什么必须是 10？**不必须。** 数学里没有任何定理规定"人类必须用 10"。我们只是习惯成自然——像吃饭用右手。所以下一节的主角登场：另一个文明选择的完全不同的一副牌。

## 3.2 二进制：计算机的母语

二进制（base-2）的世界里，只有两个成员：**0 和 1**。

- 位值：2⁰=1（个位）、2¹=2（第二位）、2²=4（第三位）、2³=8……
- "10"在二进制里不是"十"，是"二"：写法的意思是 **1×2¹ + 0×2⁰ = 2**。

来了一个诡异但重要的事实：**同一个写法"10"，在不同进制里指不同的量。** 这一开始像玩文字游戏，直到你意识到：**数字是货物，进制是包装。** "10"在十进制里是十，在二进制里是二，在十六进制里是十六——包装各不相同，货物跟随包装确定。

**计算机为什么选二进制？** 三个原因，都很硬：

1. **电路只有两种稳定态：** 通电/断电、高电平/低电平、开/关。二进制的数字太难比"断/通"更天然。
2. **抗干扰、可靠：** 只有 0 和 1，识别"是/否"远比识别"电压是 3.7 还是 3.8 伏"稳。
3. **逻辑运算恰好两值：** 真/假、是/否，正好落在布尔逻辑的范畴（第五部分·5-04 计算机科学会落地）。

**代价**（很多人会忽略的公平交易）：二进制的写法很长。数 100（十进制）写二进制是 1100100，七位。所以十进制的"手感"便宜，二进制的"电手感"贵——计算机用长度换可靠，人类用可靠换长度。任何进制都不是"免费的聪明"。

## 3.3 二进制的亲戚：八进制与十六进制

二进制对人不友好（太长），十进制对机器不友好。工程师找到了"，介于之间"的方案：

- **八进制（base-8）**：每 3 位二进制并成 1 位八进制（8=2³）。
- **十六进制（base-16）**：每 4 位并成 1 位十六进制（16=2⁴），所以十六进制需要 16 个符号：0~9 加 A、B、C、D、E、F。

**思想：进制只是"装货物的不同盒子"，互相可以翻译。** 同一个数，用二进制、八进制、十六进制写出来，只是换了三种口音，货物没有变。转换有纯机械的算法（"除基取余"），不展开——留给"估算"能力（5-07 生活）去玩。

## 3.4 位值制：所有进制的共同灵魂

回忆 0-01.1 的结论：位值制的发明，是数学史上"脱离临摹、进入抽象"的一跃。这一章的三节其实就是同一个灵魂换三套表：

| 进制 | 命名的数位 | 一句话性子 |
|---|---|---|
| 十进制 | 个十百千 | 人类手指的偏好 |
| 二进制 | 1, 2, 4, 8… | 电路最短的语言 |
| 十六进制 | 1, 16, 256… | 二进制的"速写本" |

**位值制的核心，是"位置决定价值"。** 这个思想在数学里反复横跳：坐标（第4部分）的本质，"地位决定影响力的位置"，就和位值制是远房表亲。甚至更重要的是——**它让我们放下了"数是写在纸上的记号"这件事，转而理解"数是抽象的对象，记号只是它的一件衣裳"。**（0-01.2 曾说过：符号是衣裳，不是骨架。）

## 误区（本局小结）

1. **"二进制只有 0 和 1，所以更简单"** 错——它只是符号少，位数长，没有免费午餐。
2. **"10 在哪个进制里都一样是十"** 错。"10"只是个写法，在二进制里是 2。再强调：数字是货，进制是包装。
3. **"小数只有十进制能写"** 错。任意进制都有小数：二进制里 0.1 表示 1/2。
4. **"X 进制是 X×X×…"** 慎用直觉：写成"XX"离真相最远的地方是不同进制之间——不同进制之间必须翻译，不能直接拼。
5. **"五花八门，记不住"**：记住一句——位值制 = 位置决定价值，基决定位值比例。
