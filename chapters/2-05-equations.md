# 2-05 方程：给未知数画像

> 计算章一路教会我们把已知的数摆弄来摆弄去。方程提出相反的问题：**"有一串数我不知道，但它满足一个等式，请把它找出来。"** 这是代数的看家本领——从"算已知"到"找未知"。而一元二次方程这一小节，会第一次同时接上三个方向：复数（1-07 的裂缝）、抛物线（2-04 的图像）、以及判别式这个"预言家"。

---

## 5.1 把未知数请出来：移项的秘密

方程的形式：**含有未知数的等式**，如 3x + 2 = 11。解方程的套路只有一件事：**把 x 挪到一边，把数挪到另一边。** 挪的法则是"两边同加、同减、同乘、同除"（保持等式平衡），这就是所谓的**移项**。

为什么"移项"合法？因为等式两边是**同一个量**（= 的定义，0-03.5），只要对两边做**同一个动作**，等号就被"冻结"在真上。这是全书最根本的"同一性守恒"：

$$ 3x + 2 = 11 \;\Rightarrow\; 3x = 9 \;\Rightarrow\; x = 3 $$

解方程的全部心法：**步步为营，每次动两边。** 这不是数学的魔法，是"等式天平"的物理直觉：天平两端不放同一块砝码，就会失衡。

这个"天平"的比喻，是全章乃至全代数的灵魂，值得你随身携带。想象一个旧式天平，左盘右盘放着同样重的东西，天平平衡。**等式就是"平衡的天平"**：你可以往两边加同样重的东西、减同样重的、翻同样倍数——只要动作对称，平衡就永远保持。解方程，就是一路做对称动作，直到"x 孤零零站在一边"。**天平不倒，等号不破。** 记住了这个画面，你就再也不会在移项时弄错符号——因为每次动，都是"两边一起动"。

## 5.2 一元二次：判别式与求根公式

最高级的一种方程，是"x² 出现"的二次方程：

$$ ax^2 + bx + c = 0 \qquad (a\neq 0) $$

它有一个**通用求根公式**：

$$ x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a} $$

不用背推导，但必须看懂三个"身份牌"：

1. **判别式 Δ = b² − 4ac** 是"裁判"：
   - Δ > 0：两个不同实数解。
   - Δ = 0：一个实数解（两解重合，"重根"）。
   - Δ < 0：无实数解——但注意，**在复数世界（1-07）里它仍有解，且是两个**！±√(负) 正是虚数 i 上岗的地方。
2. **±√**：根号只取非负（0-03.6），但方程要两个解，于是让 ± 把"两个候选"都接住。
3. **与抛物线（2-04）的合体**：方程 ax²+bx+c=0 的解，正是抛物线 y=ax²+bx+c 与 x 轴的交点。判别式 > 0 就是"抛物线与 x 轴交两次"，= 0 是"相切一次"，< 0 是"够不着 x 轴"。

**这就是"三线交汇"**：同一个 Δ，代数上决定解的个数，几何上决定交点数，复数上决定"有没有虚解"。一本书讲到这里，数、形、数系第一次捏成一团——这是全书最值得慢下来的一页。

这个"三线交汇"值得你停一停，因为它是全书第一次把三栋楼同时点亮：**代数说"几个解"，几何说"几个交点"，复数说"虚解藏不藏"——三个说法，说的是同一件事。** 一个判别式，同时是裁判、是预言家、是数形之间的翻译官。你一旦看懂这一页，"数学各部分其实是通的"这个信念，就会从口号变成体感。

## 5.3 方程组：消元，把一团乱麻拧成一根线

当未知数不止一个，方程也不止一个，就进入**方程组**。目标：**消元**——把"两个未知数"削成一个。

- **代入法**：用一个方程解出 x，代进另一个。
- **加减消元法**：把两个方程乘合适的数后相加/相减，削掉一个未知数。

例题：x + y = 10，x − y = 2。两式相加得 2x = 12，x = 6，代回 y = 4。

**直觉**：方程是"信息"，方程组是"多条线相交于一点"。几何上，两个一次方程是两条直线，它们的解是**交点**——这就是"直线与直线相遇"的数形结合，也是第四部分坐标（4-01）的预告。方程组为什么"解出来正好是交点"？留到坐标系章揭晓。

"消元"这个名字，本身就说尽了方法：**两个未知数，两团乱麻，先硬生生拧掉一个，剩下的就好解了。** 这背后是一个通用的处世智慧——面对一堆纠缠在一起的东西，先别急着一次全解，**先削掉一个，让问题降维**。解方程组如此，后面解矩阵（2-06）也如此，甚至生活里"先解决一个再说"也如此。数学的方法，常常是人生方法的一个缩影。

## 5.4 不等式：比较，不是相等

不等式的世界（<、>、≤、≥，0-02.2 的字汇），和等式共享大部分规则，**只有一条致命例外**：

> **不等式两边同乘（或除以）一个负数，不等号方向反转。** −2x < 6 ⇒ x > −3。

为什么反转？用数轴想：乘 −1 等于把数轴"翻面"，左右互换，所以"谁在左谁在右"对调。这一条"负号翻转"的规则，是初学者跌断腿的地方，务必记死。

**解不等式 ≠ 解等式**的另一细节：不等式的解往往是**一个区间**（x > 3 表示一整段数轴），不像方程是一个"点"。

## 5.5 误区：乘 0、除以未知数

两个"看起来人畜无害"的操作，是方程两大陷阱：

1. **两边乘 0**：两边同时乘 0，得到 0=0，一切方程都"成立"——**这一步删光了所有信息**，等于把问题洗掉重来。所以"两边同乘一个数"的前提是：这个数 ≠ 0。乘 0 合法，但等于自废武功。
2. **除以未知数**：x(x−1) = 0，很多人"两边除以 x"得到 x−1=0，x=1——**丢掉了一个解 x=0！** 因为除以 x 时，等于默认"x≠0"，可 x 恰恰可能是 0。**规则：不要轻易除以未知数；非除不可，先假设它≠0，最后再把"=0 的解"补回来。**
   （这也是一元二次、二次函数"判别式"那类问题的根源：**丢失解，往往发生在"除以可能为零的量"时。**）

---

## 误区（本局小结）

1. **方程两边同乘 0 没问题** —— 会删光信息（0=0）。
2. **两边除以未知数安全** —— 可能丢解（x=0 的那一支）。先讨论是否为零再除。
3. **判别式 <0 就没解** —— 在实数里对，在复数（1-07）里它有两个解，±√(负)。
4. **不等式乘负数不翻号** —— 必须翻号，因为数轴翻面了。
5. **方程是"背公式"** —— 核心是"天平平衡 + 移项"，公式只是结果。
6. **解方程组就是"死算"** —— 核心是"消元降维"，先削一个未知数，是贯穿代数的处世智慧。
