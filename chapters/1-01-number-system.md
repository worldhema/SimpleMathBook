# 1-01 数系大厦

> 这本书的第一块地基。你会发现一个反直觉的事实：**我们小时候学的数，没有一个是"天生就有的"。** 自然数、0、负数、分数、无理数，每一个都曾经被人激烈地拒绝过。数系的历史，是一部"人类被自己的问题逼着扩容"的编年史。这一章我们不学公式，我们盖楼——看着每一层是怎么因为"不够用"而被搭起来的。

---

## 1.1 自然数与 0：从"数还够用"到"有个洞"

最原始的一层，是 **自然数（natural numbers）**：1、2、3、4……它的出生不需要理由——数羊、数米、数人，人类天然需要"还有几个"。

但自然数刚出生就背着一个洞：**"一个都没有"用什么表示？** 猎人不数羊，他只会说"没了"。这个"没了"，拉丁文化里长期没有一个专属的数词。而上一章（0-01.1）我们讲过，是位值制逼出了 0——印度人最先把它从"占位空位"扶正成"一个数"。

第一层下面是两个钉子，提前钉下去：

- **0 是自然数吗？** 世界各国的教材意见不一（中国小学教材默认"自然数含 0"，很多科普书倾向"正整数才叫自然数"）。本书立场：**这是一个约定问题，不是事实问题。** 你只要意识到"表达上有人含 0、有人不含"，遇到规定时看清楚即可。详见本章第 6 节。
- **自然数是"数的极简款"**，够数东西，却不够记账、不够分东西、不够量长度。下面每一层，都是"不够"逼出来的。

## 1.2 负数：被拒绝了一千年的亏欠数

自然数与自然数做减法，会越界：**3−5 是多少？** 答案是"负二"——一个比什么"没有"还少的数。历史上这叫负数（negative numbers）。它的际遇，用"拒绝"两个字最准确：

- 古希腊人觉得"负"违背直觉——"你怎么能比一无所有还少？"
- 中国古代《九章算术》最早允许负数和红黑筹码（红正黑负），那是世界历史上很早的负数实践，比欧洲早一千多年。
- 欧洲文艺复兴的数学家虽然已在账本上用负数，但心里始终发虚，把负数称为"虚构的数""荒谬的数"，在某些国家，"负数是不是数"的争论一直吵到 19 世纪。

**负数是"数不够用"逼出来的第 2 层。** 它补上的缺口是"减法无界"——有了负数，任何减法都有答案，数轴从"只有右半边"补成了"左右对称的一条线"。

**最容易误解的一点**：负数不是"一减掉就是亏"，它和"方向"天然相关（温度零下、海平面以下、账目负债）。这个"方向感"，到（第三部分·几何）和（第四部分·向量）会成为几何与物理的共同语。

## 1.3 有理数：一场天大的翻译事故

第 3 层，由除法逼出：**1÷3 是多少？** 自然数和负数里都没有答案。分数/有理数登场。

有理数（rational numbers）的定义简单到让人疑惑：**能写成两个整数之比 a/b（分母≠0）的数。** 整数、0、负数、小数（包括循环小数）统统在这层。

**这里藏着你点名要的"翻译事故"。** "有理数"这个中文名，来自英文 rational（合理的），而 rational 译自拉丁文 ratio（**比、比率**）。数学家保罗·沃尔伯格（Paul Wait）等考证：拉丁 ratio 在"比"的含义上被译成"理/合理"，于是写着"合理 a"的 rational numbers 本意其实是"**比数**"（可以写成两数之比的数），被译成"有理数"后，一句话里出现了两个假象：

1. **"有理"是假的**——它完全没有"合理"的意思，纯粹是 ratio=比 的误译。
2. 教室里的困惑油然而生："为什么分数叫'有理数'？它比无理数更讲道理吗？"——不是，它只是"**可喻为两数之比**"。

记住这两点，你才算真正"看见"了第三个钉子：**分数不一定有理数的全部**，有理数的完整画像是"能写成整数之比"。判断题："3.14159…（无限不循环）是有理数吗？" 答案：不是——能不能写成整数之比，眼睛看不出来，得证明（下一节就来）。

## 1.4 无理数与 √2 危机：连"数"都差点崩盘

第 4 层，是数学史上第一次"科学的震中"。

毕达哥拉斯学派（公元前六世纪，南意大利）有一句近乎信仰的宣言：**"万物皆数"**，他们说的数是整数和整数之比（即有理数）。用勾股定理——直角边各为 1 的直角三角形斜边长是 √2——学生的宿命提问来了：**√2 能不能写成整数之比？**

答案是：**不能**。数学史上第一个"反证法"的名场面对此给出判决。大意是：

- 假设 √2 = a/b，且 a、b 是最简整数（没有公因数）；
- 平方得 2b² = a²，于是 a² 是偶数，即 a 是偶数，设 a=2c；
- 代入得 2b² = 4c²，即 b²=2c²，于是 b 也是偶数；
- 于是 a、b 都是偶数——与"最简"矛盾。所以 √2 **不是任何整数之比**。

据说这个发现让毕达哥拉斯学派惊恐——他们原本确信凡存在的都能写成"比"。传说他们把发现的人扔进海里灭口（史实上有争议，但它成了数学史上最有名的"灭口故事"）。从此，**"不能用两个整数之比表达的数"被迫成立，叫做无理数（irrational）**。

注意到没有——又是一场翻译事故：irrational 在这里的意思也只是"**非比值**"（not a ratio），与"不理智"毫无关系。中文"无理数"三个字，再一次把"非比数"译成了"不合理的树"。

**无理数毕业第 1 问：** 3.14159…（π）是无理数吗？——是，但它的证明整整花了两千年（1882 年林德曼证明 π 不仅仅是无理，更是超越数，见 1-06）。

## 1.5 实数轴：把所有的数排成一队

第 1.1 到 1.4 的四层，最终合并成一个完整的地图——**实数轴**：

```
----●----●----●----●----●----
  -2   -1    0    1    2    ...
```

实数轴是一个无限延伸的横线，每个实数都对应轴上的一个点，反之每个点都对应一个实数。**数轴的存在本身，就是"数"与"几何点"的第一次正式接吻**——这一吻之后，数与形互相翻译的时代开启，是（第四部分·坐标）的地基。

数轴带给我们的直觉是决定性的：

1. **顺序感**：数有大小，从左到右递增。
2. **距离感**：3 与 7 的距离是 |7−3|=4（回顾 0-02.3 的绝对值）。
3. **稠密**：任何两个不同的实数之间，永远夹着无穷多个别的实数（想一想：0 和 1 之间还有 0.5，0 和 0.1 之间还有 0.05……没有"相邻"的实数）。

但数轴也藏着一个让几代人心打颤的反直觉：**"有理数这么多，无理数有多少？"** 答案是：多得多。这个"多得多"不是错觉，是一个可以证明的结论（用希尔伯特旅馆的思想，见 1-02），届时你会第一次见识：无穷也分大小，而无理数甩出有理数两条街。

最后一层（实数）之上，还有一个**更高级的敞口**：数轴上的数都能"画出"吗？——能。但 x²=−1 在数轴上**画不出来**，它不属于实数。这道裂缝通向复数（1-07）。数系大厦到此盖到第 5 层，复数那一层，等我们把"计算"部分读完再封顶。

## 1.6 误区专场：这场地基上最难的三道题

### ① ÷0 为什么"不行"

**1÷0 是多少？** 先试着猜一个答案：如果有某个数 x 满足 1÷0=x，那么照"除法是乘法的逆运算"，就应有 0×x=1。可是 0 乘任何数都得 0，永远得不到 1。

- 结论①：1÷0 没有解，因为"逆运算定义失败"。
- 那 **0÷0** 呢？如果有 x 使 0÷0=x，需 0×x=0——**任何 x 都满足**。不是"无解"，而是"人人都是解"，一样无法定义。
- 于是数学严格起来的规则是：**分母 ≠ 0。** 计算机程序写 1/0 会报 "Division by zero"，正是这条规则的执行。

**别忘了，有一个委屈的亲戚**：这件事和 0.99… 无关，也绝不是说"0 不能出现在除法里"——0÷5=0 完全合法。禁的是"**做分母**"。

### ② 0.999… 到底等不等于 1

结论先给：**等于**。而且证明简单到令人难过：

```
设 x = 0.999…
则 10x = 9.999…
10x − x = 9.999… − 0.999… = 9
9x = 9
x = 1
```

为什么人们总觉得"差一点点"？因为直觉把 0.999… 当成"越来越接近 1 但永远差一点"的**过程**。不是的——0.999… 写成"三个点"的那一刻，它是一个**静止的、完整的、写完所有 9 的数**，不是动态逼近。过程是"1−0.999…=0"（差为 0），不是"差一点点"。这是全书最重要的"直觉与事实分居"样例：**文字广场上的"差一点"，在数轴上是"同一个点"。**

### ③ 0 是自然数吗（顺带：0 到底算不算"有"）

复习 1.1 的庭审结论：**约定问题，不是事实问题。** 中国现行教材通常把 0 算作自然数（自然数 = {0, 1, 2, …}），许多出版文献仍写自然数不含 0。书中用到"正整数""非负整数"这类词时，请看清它说没说起点——mathematics 的真实世界录用"谁说了算，谁先写清楚"。

### ④ 负数的"负"字

理性认识：**负数不是一个哲学概念，是数轴上原点的左边邻居。** 它和"方向"绑定（温度、海平面、负债），并将在向量（4-05）焕发青春。

---

## 误区（本局小结）

1. 0 是自然数吗／是约定不是事实。
2. 1÷0 无解、0÷0 无法定义——规范是"分母≠0"。
3. 0.999…=1 是**静止事实**，不是"越来越接近"的动态过程。
4. "有理数"的本意是"比数"，"无理数"本意是"非比数"，两者都与"道理/理智"无关。
5. 无理数不是"少见的怪数"——数轴上它的数量比有理数"多得多"（1-02 见分晓）。
6. 负数不是"比没有还少的神秘存在"，是"数轴上原点的左邻居"、方向的起点。
