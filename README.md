# 简单数学

> 一本从地基盖到屋顶的数学科普书。

## 这本书想做什么

数学经常被看成两样东西：要么是"死记的公式"，要么是"天才的魔法"。这本书想说的是第三种可能——**数学是一座楼**。

楼的每一层都踩在前一层上面：

```
第〇部分  数学的语言        —— 砖与砖之间的灰浆：符号
第一部分  数               —— 地基：数从哪来、有哪些
第二部分  计算与代数       —— 承重墙：运算与函数
第三部分  几何             —— 骨架：形与空间
第四部分  数与几何的结合   —— 把墙和梁接起来：坐标
第五部分  数学与实践       —— 屋顶之上看风景：数学怎么用
结语      一栋楼俯瞰
```

我们按这个顺序一层层往上盖。每一章末尾有一个小框叫「误区」，收集人们最容易想岔的地方——**这本书最费心思的不是"教"，而是"纠"**。

全书只有一个小小的要求：**别跳层**。跳级盖楼会踏空；从第一页开始，一层一层往上，你会发现数学并不神秘，它只是老老实实地逐层生长。

## 阅读路线

- **普通读者**：从第〇部分第一页读到底，别跳层。
- **赶时间**：至少读 1-01（数系大厦）、2-03（对数）、3-05（圆）、4-06（欧拉公式）四章，它们分别是地基、暗梁、立柱和屋顶。
- **数学恐惧者建议先读**：0-03 容易混淆的符号对 + 1-01 数系大厦，先解开"最扎手"的两处再动身。
